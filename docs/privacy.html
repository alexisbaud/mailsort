Privacy policy

mailsort · Last updated November 24, 2026

Who uses mailsort

mailsort is a personal tool written and operated by Alexis Baud. It is used only by its owner, on his own Gmail account. It is not offered to the public, has no other users and collects no data about anyone else's account.

Google permission requested

mailsort requests the https://www.googleapis.com/auth/gmail.modify scope. It uses it only to read messages and to add or remove labels on them. mailsort never sends email and never permanently deletes email.

What is read, and why

  • Message headers: sender, recipients, subject, date and mailing-list headers.
  • Message content: the text and HTML body of each message.
  • Threads: which messages of a thread were sent by the owner and when, to know whether he already replied.
  • Attachments: only their file names. Attachments are never downloaded and their content is never read.

This data is read for a single purpose: classifying each message and applying the matching labels in the owner's Gmail account.

What is sent for classification

To decide which labels apply, mailsort sends a summary of each message to Jev, a classification model operated by TypeSafe, through its API. The summary contains: the sender's name and address, whether the owner is a direct recipient, in copy or reached through a list, the subject, the date, whether mailing-list or unsubscribe indicators are present, attachment file names, whether the owner already replied in the thread, and the message text after cleaning (links, invisible characters, quoted replies and signatures removed), limited to about 5,000 tokens. Jev returns probabilities, from which mailsort decides the labels. TypeSafe states that Jev is not trained on customer requests.

What is stored

mailsort keeps a local database on the owner's own machines with Gmail message and thread identifiers, dates, the probabilities returned by Jev, the labels applied and the owner's manual corrections. It does not store the text, subject or sender of any message.

Sharing

Gmail data is not sold, not shared with anyone other than the classification service described above, and not used for advertising, marketing or any purpose other than labeling the owner's own inbox. No human other than the owner reads it.

Limited Use

mailsort's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Security

The OAuth token is stored only on the owner's own machines (his personal computer and his private VPS), in a file readable only by the owner (permissions 600), and is never committed to source control. API keys are kept the same way.

Revoking access and deleting data

Access can be revoked at any time from https://myaccount.google.com/permissions. After revocation mailsort can no longer read or label messages. The local database can be deleted by the owner at any time.

Résumé en français

mailsort est un outil personnel utilisé uniquement par Alexis Baud, sur sa propre boîte Gmail. Il demande le droit gmail.modify pour lire les messages (en-têtes, contenu, fils) et y poser ou retirer des labels ; il n'envoie et ne supprime jamais de mail. Les pièces jointes ne sont jamais téléchargées, seul leur nom est lu. Un résumé de chaque mail (expéditeur, objet, date, indices de liste de diffusion, noms des pièces jointes, texte nettoyé et tronqué) est envoyé à Jev, le modèle de classification de TypeSafe, pour décider des labels. La base locale ne garde que des identifiants, des probabilités et des labels, jamais le texte des mails. Rien n'est vendu, partagé ou utilisé pour de la publicité. Le jeton d'accès reste sur les machines du propriétaire (ordinateur personnel et VPS privé), avec des droits restreints. L'accès se révoque sur myaccount.google.com/permissions.

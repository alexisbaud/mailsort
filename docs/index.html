mailsort

mailsort is a personal, self-hosted tool that automatically sorts and labels the Gmail inbox of its owner. It has no public user interface and is not offered to the public.

Three times a day, it reads new messages in its owner's Gmail account, asks a classification model which labels apply, and adds or removes those labels. It never sends or permanently deletes email.
